A newspaper front page that sums up the world's news of Saturday 21
November 2026 in one image: missiles and a drone fall on Poland, US stocks
enter correction territory, Cyclone Akvan crosses the Odisha coast, the ICJ
rules on Myanmar and the Rohingya, COP31 reaches its final stage, a UK–EU
summit, the first Trump–Xi–Putin trilateral summit, and the Gulf — plus a
briefs strip with the cyberattack on payment vendors, the GTA 6 launch and
the Wellington Test.

`draw_image.py` draws `entry.png` (1024×1024) with Python and Pillow,
deterministically — no randomness, no network, no clock. `main.ts` copies
`entry.png` to `MAKEFUN_OUTPUT_DIR` (or `/output`).

Run it:

```sh
python3 draw_image.py
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
